# Archived analysis scripts

One script per finished experiment, kept as the record of what was
pre-registered (each was committed before its runs existed). They ran against
the code at the time and are **not maintained**: the cleanup after
bc-finetune moved them here, removed settings some of them use, and changed
the default game, so most will not run on current code. To rerun one, check
out the commit before that cleanup (b4b5ffa) and use its original path,
`analysis/<name>.py`.

Results and verdicts are in EXPERIMENTS.md; raw outputs in `results/`.

Shared measurements for new experiments live in `hockey/measure.py`.
